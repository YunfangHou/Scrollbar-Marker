# Scrollbar Tag

一个轻量的 Chrome 扩展，在网页原生滚动条左侧显示位置标签，并可一键滚动回标签位置。

## 安装

1. 打开 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹。

## 使用

- 点击页面右下方半透明的 `+` 添加当前位置；也可以拖动它并将位置保存在不同网页间。
- 或点击 Chrome 工具栏中的扩展图标。
- 或在设置页中自定义快捷键；新安装默认不设置快捷键。
- 点击标签可平滑滚动到对应位置。
- 右键点击标签可打开编辑气泡，选择八种颜色之一、填写备注、删除单个标签或删除当前网页的全部标签。
- 备注在输入时自动保存，按 Enter、Escape 或“关闭”只需关闭气泡。
- 备注输入框可被 Vimium 等键盘导航扩展识别，输入字符时不会触发页面快捷键。
- 备注会显示在标签上，常态宽度最多为页面宽度的 5%，悬停时最多展开至 10%。
- 标签按完整网址（忽略 `#` 锚点）保存在 Chrome 本地存储中。

## 设置

右键点击 Chrome 工具栏中的扩展图标，选择“自定义设置”，即可：

- 控制页面右下角的 `+` 是否显示。
- 选择之后新建标签的默认颜色。
- 查看当前快捷键并打开 Chrome 的扩展快捷键设置页，自定义快捷键。
- 查看所有含标签的网页、favicon 和标签数量，并逐项删除。

Chrome 不允许网页脚本直接向浏览器原生滚动条内部添加交互元素，因此标签轨道紧贴在滚动条左侧。
